## 측정 상태

- 상태: 수정 전 기준선
- 장비: GL.iNet Opal + Nikon D810
- 연결: 로컬 LAN `192.168.8.1`
- Tailscale SSH 및 외부 포트 공개 없음
- 카메라 설정: RAW + Fine JPEG
- JPEG 크기: `7360×4912` 약 36.2MP
- JPEG 파일 크기: 약 `24.8–24.9MB`
