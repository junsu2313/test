# 9MP JPEG 전 구간 재검증 — 2026-07-28

## 조건

- 장비: GL.iNet Opal + Nikon D810
- 연결: 로컬 LAN `192.168.8.1`만 사용
- 저장 설정: RAW는 36.2MP 유지, Fine JPEG는 `3680×2456`(약 9MP)
- 비교 기준: 36.2MP JPEG 3회 기준선
- 측정 경로: UI `SHOT` → 미리보기 표시 → 미리보기 선택 → 원본 표시

## 36.2MP 기준선 대비

| 항목 | 36.2MP | 9MP | 변화 |
| --- | ---: | ---: | ---: |
| JPEG 파일 크기 | 약 24.9MB | 6.771MB | **72.8% 감소** |
| 미리보기→원본 표시 | 9.146초 | 3.519초 | **61.5% 단축** |
| 전체 사용자 체감 | 13.293초 | 7.683초 | **42.2% 단축** |
| 서버 원본 처리 | 8.737초 | 3.216초 | **63.2% 단축** |
| PTP wire | 6.355초 | 1.857초 | **70.8% 단축** |
| Opal socket write | 1.402초 | 0.397초 | **71.7% 단축** |

미리보기 도달 시간은 4.147초에서 4.163초로 사실상 동일했다. 이번 설정의 이득은 촬영 준비 구간이 아니라 JPEG 크기와 원본 전송 구간에서 발생했다.
