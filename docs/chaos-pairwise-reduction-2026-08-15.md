# 제약 기반 페어와이즈 시험 축소 결과

## 결론

| 단계 | 경우의 수 |
|---|---:|
| 26개 관측 인자의 원시 상태 | 187,861,869,527,040 |
| 불가능한 상태를 제거한 관측 스냅샷 | 996,741,365,760 |
| 14개 실행 제어 인자의 원시 조합 | 55,987,200 |
| 실행 제약을 적용한 유효 조합 | 6,426,810 |
| 유효한 값의 쌍 | 1,152 |
| 생성된 시험 행 | 52 |

시드 810으로 생성한 52개 시험은 유효한 1,152개 값의 쌍을 모두 한 번 이상 포함한다. 따라서 유효 페어 커버리지는 100%다.

## 축소 원칙

약 9,967억 개는 시스템에서 관측 가능한 상태의 수다. 이를 그대로 시험 입력으로 사용하면 원인과 결과가 섞이고 실행할 수 없는 상태도 포함된다. 실행표에서는 사용자가 직접 설정하거나 장애로 주입할 수 있는 항목만 14개 제어 인자로 변환했다.

그 뒤 재부팅과 개별 프로세스 장애의 중복, 전송이 없는데 전송 중 장애가 발생하는 경우, 체크포인트 작업이 없는데 체크포인트 중단이 발생하는 경우 등 9개 실행 제약을 적용했다. 그 결과 실행 가능한 전체 조합은 6,426,810개가 됐다.

페어와이즈 단계에서는 이 유효 공간에서 실제로 성립하는 모든 두 인자 값의 조합만 요구사항으로 삼았다. 총 1,152개이며, 제약을 만족하는 후보 행을 생성한 뒤 탐욕적 집합 덮기와 중복 제거를 적용해 52개 행으로 덮었다.

## 보장 범위

- 52개 행은 모두 실행 제약을 만족한다.
- 1,152개 유효 페어는 모두 최소 한 번 등장한다.
- 기준 정상 상태는 첫 번째 행에 고정된다.
- 과전류 주입과 저장소 완전 고갈은 안전상 실행 인자에서 제외했다.
- 시드와 후보 생성 순서가 같으면 결과가 동일하다.

이 결과는 전역 최솟값을 수학적으로 증명한 것이 아니다. 현재 알고리즘과 시드로 얻은 재현 가능하고 검증된 52행 커버링 배열이다. 또한 3개 이상 인자의 고차 상호작용까지 전부 보장하지는 않는다. 그런 위험은 별도의 선별된 복합 시나리오로 보완해야 한다.
