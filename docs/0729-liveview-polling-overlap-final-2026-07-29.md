## 변경
- 다음 `0x9203` 요청을 먼저 전송하고, 카메라 응답 대기 중 이전 프레임을 스트림으로 전달한다.

## Opal + D810 60초 실측
- 전체 프레임 요청 공백: 평균 `1.638 ms`, p50 `0.632 ms`, p95 `3.048 ms`
- 목표 마진 `1.8~1.9 ms` 대비 평균 기준 `0.16~0.26 ms` 여유
- 실생산: `3632 frames / 60.01 s = 60.52 fps`
- UI 1초 이동창: 평균 `60.96`, p10/p50/p95 `56.5 / 60.8 / 65.4 fps`
- UI 지연: 평균 `15.07 ms`, p50/p95/최대 `15 / 16 / 16 ms`
- 캐시 기록: `59회 / 60초 = 0.983 Hz`
- CPU busy: `45.01%`, Bridge `16.35%`, WebSocket `8.98%`
- frame failure `0`, reconnect `0`, 배터리 `100%`

UI와 생산 FPS의 60 초과 값은 1초 이동창과 시계 오차가 포함되므로 카메라가 60fps를 초과 생성한다는 증거로 사용하지 않는다. 결과는 상시 `60fps급`으로 고정한다.
